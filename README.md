# Harsh Sharma - portfolio

Plain HTML/CSS/JS, no build step.

## Edit in the browser: /admin.html
Open your-site-address/admin.html, paste your GitHub token once, then edit text, reorder or hide films and stills, add pictures, and press Save changes. The live site updates in about a minute.
Contact details (email, phone, links), the About text and every film description are all editable there. Leave a blank line in a long text box to start a new paragraph.

## Edit by hand
Everything is in content.js on GitHub (pencil icon, then Commit changes). Pictures sit next to index.html.
